Mini Control Overview Architecture API Deploy

REST API

Base URL https://<server>. Most endpoints take a Bearer token; browser endpoints are authenticated by Cloudflare Access. Token comparison is constant-time.

On this page Auth Public Member Workers VMs Proxy Releases

Authentication

Authorization: Bearer <admin_token | worker_token>

Browser-facing member endpoints expect the Access JWT in Cf-Access-Jwt-Assertion, validated against the configured audience and issuer.

Public

EndpointDescription
GET /api/v1/healthHealth check — {"status":"ok"}.
GET /install.shWorker setup script (server address injected at serve time).

Member (Cloudflare Access)

EndpointDescription
GET /api/v1/meCurrent authenticated member.
GET /api/v1/browser/workersWorkers and their reported VMs for the browser.
GET /api/v1/my-workstationThe member’s dedicated workstation (resumed if stopped).
POST /api/v1/my-workstation/claimClaim or move a workstation; optional worker_id.
POST /api/v1/my-workstation/releaseMark the workstation for deletion.
POST /api/v1/browser/proxy-sessionsCreate a browser proxy session for port 5900 or 22.
GET /api/v1/browser/terminal/wsWebSocket terminal; the server bridges SSH.

Workers

EndpointDescription
POST /api/v1/workers/registerRegister with enrollment_token (first install) or a per-worker worker_token; issues a worker token on enrollment.
GET /api/v1/workersList workers and VMs (auth).
POST /api/v1/workers/{id}/heartbeatHeartbeat; updates VM states (auth).
POST /api/v1/hostname/assignAssign a sequential mac-N hostname (enrollment auth).

VMs

EndpointDescription
PUT /api/v1/vms/{id}/stateUpdate VM state; destroying deletes the record (auth).

VM states: starting · bootstrapping · ready · busy · destroying · failed. Worker status: active · draining · offline.

Proxy

EndpointDescription
POST /api/v1/proxy/sessionsCreate a TCP proxy session (e.g. VNC forwarding) for a VM or host (auth).
GET /api/v1/proxy/sessions/pendingPending sessions for a worker (auth).
GET /api/v1/proxy/wsWebSocket relay; role=client|worker, token via query param.

Releases

EndpointDescription
GET /api/v1/releases/latestMetadata for the most recent release.
GET /api/v1/releases/download/{version}Download a release binary.
PUT /api/v1/releases/upload/{version}Upload a signed binary (auth); validated against required_signing_identity.

Full request/response shapes live in docs/api.md in the repository.
